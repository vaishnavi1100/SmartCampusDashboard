# Smart Campus Dashboard
A responsive university dashboard designed using HTML, modern CSS and JavaScript.
## Features
- Responsive dashboard with four information cards.
- Light Mode and Dark Mode toggle.
- Reusable CSS design tokens using CSS variables.
- Modern CSS `:has()` selector.
- Container queries using `@container`.
- Interactive hover effects.
- Smooth card entrance animations.
- Reduced-motion accessibility support.
- Responsive layouts for desktop, tablets and mobile devices.
## Technologies Used
- HTML5
- CSS3
- JavaScript
## Dashboard Sections
1. Campus Events
2. Student Clubs
3. Announcements
4. Campus Services
## Performance Optimization
The dashboard uses reusable CSS variables, lightweight animations, efficient transitions and responsive styling to maintain a consistent user experience across devices.
## How to Run
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the theme toggle button to switch between Light Mode and Dark Mode.
